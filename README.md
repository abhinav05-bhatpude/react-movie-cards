# 🎬 Movie Recommendation App

A modern React movie recommendation web app built using React and Tailwind CSS.

Users can:
- Search movies
- Filter by genre
- Explore movie cards
- Enjoy responsive UI design

## 🚀 Tech Stack

- React.js
- Tailwind CSS
- JavaScript
- Vite

## ✨ Features

- Dynamic movie cards
- Genre filtering
- Search functionality
- Responsive design
- Hover animations
- Modern UI
